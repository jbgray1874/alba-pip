Sage X3 Integration
The ledger made intelligent.

Sage X3 is the ERP backbone of many mid-market PE portfolio companies. The platform connects to it via the Sage X3 REST API, pulling real-time ledger data and surfacing it as actionable intelligence — not just numbers.

What Sage X3 gives us
General ledger entries, chart of accounts, P&L by cost centre, balance sheet, aged debtors, aged creditors, cash flow statement, purchase orders, sales orders, supplier invoices, budget vs actual variance, and multi-entity consolidated reporting — all accessible via authenticated API calls. For Sage X3 specifically (which SDI Displays uses), the API uses SOAP/REST endpoints with OAuth or API key authentication. The data lands in the drill-down system and the AI agents in the same shape as the Xero data already connected.

Resilience design
The production architecture runs across three AWS availability zones in eu-west-1 (Ireland) with a warm standby in eu-central-1 (Frankfurt). RTO of under 5 minutes, RPO of under 1 minute for all financial data. Each integration degrades independently — if Bloomberg goes down, the platform continues running on cached data tagged as stale. No single integration failure takes down the platform. All data in transit encrypted (TLS 1.3), all data at rest encrypted (AES-256), all credentials stored in AWS Secrets Manager with automatic rotation. SOC 2 Type II and ISO 27001 target for Month 9.
Cost Model
Enterprise capability at start-up economics.

One of the platform's defining characteristics is its cost structure. The serverless architecture means cost scales with usage — not with the number of integrations. Adding the 50th integration costs the same as adding the 5th.

The commercial case
A comparable enterprise portfolio monitoring platform from a tier-1 vendor (Allvue, iLevel, Dynamo) costs £80,000–£200,000 per year in licensing alone, before implementation, customisation, or integration fees. The production version of this platform delivers equivalent — and in many cases superior — capability at £15,000–50,000 per year total cost, with full control of the codebase, zero vendor lock-in, and the ability to add any integration required without a change request to a vendor. The AI agent layer alone — autonomous monitoring, instant investigation, automated board packs — has no equivalent in any existing PE/VC platform at any price point.
