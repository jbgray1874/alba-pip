Keeping the website and the platform apart is deliberate. The website is a brochure — it works, it is paid for, and moving it would cost a weekend and buy nothing. The platform needs a login, an API and a database it will eventually grow into, none of which a brochure host provides.

The one thing needed from the website is a single DNS record pointing app at Azure. Nothing else about the domain changes — and specifically not the mail records, which is the one way this could go wrong and take email down with it.

How app.alba-pip.com is secured

Six layers, from the outside in. The first five are already written and committed; they take effect the day the Azure resource exists.

EncryptionIn place
HTTPS throughout, with the certificate issued and renewed by Azure at no cost. A browser that has visited once refuses to connect over plain HTTP for a year afterwards, so the connection cannot be downgraded on a hotel or airport network.
Who you areIn place
Sign-in with a Microsoft work account. No password is set, stored or reset by us — Microsoft holds the credential and enforces whatever multi-factor rules the account already has.
Whether you are on the listIn place
This is the one that actually gates access. Signing in successfully and being let in are separate things: Microsoft will authenticate anybody with an account, so entry depends on having been invited by name. Someone who signs in without an invitation is told so plainly rather than shown an error, and sees nothing of the platform. Invitations are issued and revoked from the Azure portal in seconds.
The credentialsIn place
The keys to Xero, Stripe and HubSpot are held by the server and never sent to the browser. They are not in the source code and never have been.
Browser hardeningIn place
The site cannot be framed inside another site, cannot be tricked into running a file as the wrong type, and cannot ask for camera, microphone, location or payment — because it never should, and saying so means a script that someday tries will fail.
Injection defenceWatching first
A policy naming the only places the page may load anything from — get it right and injected code has nowhere to run. It is currently in report-only mode deliberately: it watches and reports without blocking, so it can be confirmed against a real browser before it starts enforcing. A policy switched on blind breaks pages in ways that look like ordinary bugs, and it is worth one careful session to avoid that.

What this does not protect, stated plainly. As with every website in existence, the page's own program code is delivered to the browser and can be read by anyone who reaches the site. It contains no keys and no client data — every figure in the current build is generated rather than real. When actual portfolio data arrives it will sit behind the sign-in on the server side, which is the layer that matters.

The free tier is not a trial and does not expire. It carries the sign-in, the custom address and the certificate. The first real cost arrives with a database, when actual client data goes in — on the order of £20 to £25 a month, which is worth knowing now and deciding on later.

Azure infrastructure is not where the money goes on something like this. The cost is engineering time, and that decision comes when there is a client to build it for.

What I need from you

Two things, both quick

  1. Access to the alba-pip.com account. Whoever the domain and the website sit with, I need enough to edit the home page and add one DNS record — so it does not need asking twice. Where the provider supports it, delegate access is better than sharing a password: it is revocable at any time, and a shared password does not work anyway once two-factor is on the account.
  2. Confirmation on the Azure subscription, opened against the Alba account rather than a personal one. Ownership then sits with the business, sign-in uses our own work accounts, and nothing depends on any one person's login.

Also useful, if you know: who built the website and where it is deployed from. It decides where the button gets added, and nothing else.
